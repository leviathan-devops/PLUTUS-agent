### CHANGE B: Triple-Nested Setup Loop

**File: `src/engine3/visual-setup-generator.ts` — `generateSetups()` method**

The current `generateSetups()` resolves ONE direction per day, then filters zones to match. V4.2 changes this to iterate ALL zones per day with per-zone direction.

**Current (v4.1 baseline):**
```typescript
dayLoop: for (const dayShape of days) {
  const direction = this.resolveDirection(dayShape, chain, spot, visualZones);
  // ... filters zones to single direction
  for (const category of categories) {
    const eligibleZones = this.selectEligibleVisualZones(visualZones, direction, spot, pair);
    // ... generate setups only in ONE direction
  }
}
```

**V4.2 target:**
```typescript
dayLoop: for (const dayShape of days) {
  const categories = this.getCategoriesForShape(String(shape));
  for (const category of categories) {
    // ALL zones eligible (no direction pre-filter)
    const allZones = this.selectEligibleVisualZones(visualZones, spot, pair);
    for (const vz of allZones) {
      // Direction per ZONE, not per day
      const direction = vz.type === 'SUPPLY' ? TradeDirection.SHORT
                      : vz.type === 'DEMAND' ? TradeDirection.LONG
                      : (vz.top + vz.bottom) / 2 > spot ? TradeDirection.SHORT : TradeDirection.LONG;
      // ... build setup with this zone + direction + category
    }
  }
}
```

**This is the KEY multiplier:** SS days now produce LONG at demand zones AND SHORT at supply zones on the SAME day. The golden standard Monday has SS Long + BS Short — this change enables that.

**DXY is the MASTER. EURUSD and GBPUSD are inversely correlated 1:1.** Same shapes, same setups, opposite direction. AU diverges.

- DXY LONG (USD strong) → FX falls → FX SHORT setups
- DXY SHORT (USD weak) → FX rises → FX LONG setups
- DXY NEUTRAL (SS shape) → Both directions allowed on FX

**Law 20:** DXY cascade is a HARD FILTER. DXY bearish → FX LONG only. DXY bullish → FX SHORT only. Exception: ZoC (Law 19) allows both directions at high-confluence SS zones.
