## §4 Core Insight

The implementation must produce runtime-grade software that works correctly in a real runtime environment — not just code that compiles. For this build specifically:

1. **The doctrine IS the intelligence; the substrate MECHANIZES it.** Every operator law becomes a typed structure: a lexicon predicate, a machine guard, a MathExpr oracle, a TEB enforcement surface. Zero prose-guarded contracts in the target tree.
2. **Two machines, one card.** The Card Generator and the Kernel are independently buildable, independently testable, independently replayable. Their ONLY coupling is the card schema — the same relation as JESL cards to the JESL kernel.
3. **The Aether tier is bracketed everywhere.** The ONLY place a model touches the pipeline (STEP A/B reasoning, chart verification, the kernel's generate nodes) it is bracketed by in-gate + out-gate, journaled, capped, and degradable to a deterministic fallback at confidence ≤0.70 with a LOUD manifest.
4. **Evidence triplets or it didn't happen.** Every classification, every designation, every trade carries `{Pattern, State, Evidence}` — no triplet = no finding = the decision does not exist.
5. **The kernel is replayable by construction.** The journal records every L1-L5 computation as an Activity with its causal chain — `Journal.query(causationId)` reconstructs any trade decision from the card input to the report output.

**Governing non-negotiables:** error handling on every path (a crashing predicate counts against, never silently passes — engine.ts:109-112); boundary validation (the Schema-gate refuses invalid cards with typed REFUSAL tokens); resource cleanup (Effect Scope + fiber interruption on every stage); side-effects-before-claims (journal.append BEFORE ipc.emit — the W2 law).

```
  const trades: TradeProjection[] = [];

  FOR (const candidate of candidates) {
    // 3a. Compute E/SL/TP from the zone geometry (L1 + L2)
    const anchors = computeAnchors(candidate, telescope, pressure);
      // entry = the designated zone's defended edge (the near edge)
      // sl = the ladder-steps rule (3p outside OR 1-2p inside the next rung)
      // tp = the opposing zone's internal LQZ (the structural wall)

    // 3b. Verify against the fib path (L3)
    const fibCheck = spiderweb.anchorVerification.find(a => a.tradeId === candidate.id);
    IF (!fibCheck.entryOk || !fibCheck.slOk || !fibCheck.tpOk) {
      journal.append({ trade: candidate.id, rejected: 'FIB_MISMATCH', fibCheck });
      CONTINUE;
    }

    // 3c. Verify the DXY inverse exists (L4) — EU/GU only
    IF (candidate.pair !== 'DXY') {
      const inverse = cascade.perTradeInverseMapping.find(m => m.tradeId === candidate.id);
      IF (!inverse.inverseExists) {
        journal.append({ trade: candidate.id, rejected: 'NO_DXY_INVERSE', inverse });
        CONTINUE;
      }
    }

    // 3d. Apply the warhead confluence grading (L5)
    const confluence = warheadConfluence.evaluate(candidate, anchors, telescope, pressure, spiderweb, cascade, validatedCard.reasoning);
    IF (!confluence.tradeValid) {
      journal.append({ trade: candidate.id, rejected: 'CONFLUENCE_FAIL', confluence });
      CONTINUE;
    }

    // 3e. Emit the TradeProjection with FULL provenance
    trades.push({
      id: candidate.id,
      pair: candidate.pair,
      direction: candidate.direction,
      entry: anchors.entry,
      stopLoss: anchors.sl,
      takeProfit: anchors.tp,
      rrr: computeRRR(anchors),
      provenance: {
        e1ZoneId: candidate.zoneId,
        e2DesignationId: candidate.designationId,
        l1Telescope: telescope.boMOrigins.find(z => z.id === candidate.zoneId)?.id,
        l2Pressure: pressure.pressureOverlay.find(p => p.zoneId === candidate.zoneId)?.compositePressure,
        l3FibAlignment: fibCheck.fibAlignment,
        l4DxyInverse: inverse?.dxyInverseZoneId,
        l5Confluence: confluence.score,
        l5SupportingLaws: confluence.supportingLaws.map(l => l.lawId)
      },
      journalCausationId: journal.currentCausationId
    });
  }

  // STAGE 4: Return the validated trades
  RETURN trades;
}
```
